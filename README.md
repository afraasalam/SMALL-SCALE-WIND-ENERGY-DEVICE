# 🌬 Smart Wind Energy Monitoring System

## 📌 Description
This project is used to monitor wind turbine data in real time.  
It collects voltage and current data from an online source, stores it in a MySQL database, and displays it using a dashboard.

---

## 🚀 Features
- Real-time data collection
- MySQL database storage
- Interactive dashboard using Streamlit
- AI-based power prediction
- Login system

---

## 🛠 Tools Used
- Python
- Streamlit
- MySQL
- Selenium
- Plotly
- Pandas

---

## ▶️ How to Run

1. Start MySQL (XAMPP)
2. Run:
   python main.py

3. Open dashboard:
   streamlit run dashboard.py
